# Currency Converter

A responsive web application built with vanilla JavaScript that handles real-time currency conversions using live exchange rates.

## Features
- Asynchronous live exchange rate fetching via Fetch API.
- Dynamic object data extraction.
- Robust structural error handling using 'try...catch' blocks.
- CLean, responsive UI design.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+, Async/Await)
